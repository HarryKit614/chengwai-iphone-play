## 一、行职录分四栏

| 栏 | 刷新 | 做什么 | 主要奖励 |
|---|---|---|---|
| 日常行职 | 每天 | 在场轻触、共处动作、看一段剧情 | 薪币、常用任务物 |
| 道途行职 | 每周 | 跟某位男主的「道」相关，顾山是猎户山路 | 绘符材料、行职解锁外观、少量道薪 |
| 主线行职 | 跟章节走 | 天缝、还位的推进节点 | 道薪、信物、主线解锁外观／符箓 |
| 共处行职 | 随共处状态 | 让破祠变整洁、有烟火、避好雨 | 共处用品、共处专用姿态 |

原则：做任务是为了跟他多待一会儿，不做体力，也不做强制每日打卡惩罚。漏一天不扣东西。

## 三、顾山样板任务（每栏几条）

日常行职（每天 3 条，全做完约 450 薪币）
- 在场轻触顾山 3 次：150 薪币 + 黄符纸×1
- 共处做任意 2 个动作：150 薪币 + 山叶签×1
- 看一段剧情或回顾一段：150 薪币 + 朱砂×1

道途行职 · 猎户山路（每周 3 条）
- 跟他去后山看套子（短剧情）：雨青墨×2 + 山货皮×1
- 帮他补猎服的破口（共处小事件）：30 道薪 + 解锁 hair_d 雨湿短发
- 雨夜守门一晚（共处＋剧情）：雨青墨×1 + 解锁 fu_hunt_mark 猎户山印

主线行职（跟章节）
- 第一章「渡气」通关：信物 顾山的火折子 + 50 道薪
- 第一次看见天缝：信物 天缝碎光 + 天缝金屑×2 + 解锁 fu_sky_rift
- 对应章节剧情通关：章节任务奖励 解锁 fu_24dao 廿四道天章（2026-09-25 改为章节奖励，不在天市卖）

共处行职
- 破祠「整洁」达标：干净粗布×2 + 解锁 pose_sit_fire 灶边坐姿（原表标价的替代获取）
- 「烟火」与「避雨」同时达标：木楔×1 + 30 道薪

## 四、大致节奏（量级示意）

- 只做日常：每周约 3,000 薪币，够买 2–3 件薪币外观。
- 加道途和主线：每周约 60–110 道薪，1–3 周换一件稀有外观。
- 行职解锁的外观（雨湿短发、雨蓑外袍、山叶别发、闻风侧耳、猎户山印、天缝微痕）不花钱也拿得到。

## 五、界面落点

- 行职录：四栏切页，每条任务显示奖励小图标和「去做」按钮（跳在场／共处／主线）。
- 行囊：信物｜材料｜共处用品｜兑换物 四格分页，外观部件另归衣冠，不塞行囊。
- 天市：外观｜套装｜以物换物 三栏；道薪和薪币分开标价。
